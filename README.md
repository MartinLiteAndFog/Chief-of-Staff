# Chief-of-Staff

Zentrale Ablage für strukturierte Hand-offs aus Strategie- und Sprachgesprächen.

## Struktur

- `handoffs/` – abgeschlossene Gesprächsübergaben
- `decisions/` – dauerhafte Entscheidungen
- `projects/` – Projektkontext
- `inbox/` – neue, noch ungeprüfte Inputs

## Hand-off-Schema

Jeder Hand-off enthält Kontext, Entscheidungen, Erkenntnisse, Aufgaben, offene Fragen, betroffene Projekte und den nächsten sinnvollen Schritt.
